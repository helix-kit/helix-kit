# Contributing to Helix

Contributions are accepted under the license declared for the affected files.
Software contributions are normally `AGPL-3.0-only`; documentation and non-code
media contributions are normally `CC-BY-SA-4.0`.

## Developer Certificate of Origin

Every commit must include a `Signed-off-by` trailer certifying the Developer
Certificate of Origin in [`DCO`](DCO). Sign commits with:

```sh
git commit -s
```

The sign-off must use a name and email address that identify the contributor.
It is a certification of contribution rights, not a cryptographic signature.

## Third-party work

Do not submit copied or generated material without identifying its source,
copyright holder, license, and required notices. Do not replace an existing
third-party license with the Helix license. Update `NOTICE` when attribution is
required in distributed copies.
