<a id="helix-embedded-arduino"></a>
### `helix embedded arduino` *(group)*

Arduino / AVR firmware: build, simulate (QEMU), flash, and test.

Serial-only devices (no WiFi/BLE), developed against a qemu-system-avr
simulator so no physical board is needed. See embedded/arduino/README.md.

**Usage:**

```
helix embedded arduino [OPTIONS] COMMAND [ARGS]...
```

**Subcommands:**

- [`build`](#helix-embedded-arduino-build) — Compile SKETCH (a dir path or a name under embedded/arduino/).
- [`flash`](#helix-embedded-arduino-flash) — Build SKETCH and upload it to a physically connected board.
- [`run`](#helix-embedded-arduino-run) — Build SKETCH and run it under QEMU, bridging its serial port.
- [`smoke`](#helix-embedded-arduino-smoke) — Quick serial + Helix-protocol round-trip check in QEMU (no pytest).
- [`test`](#helix-embedded-arduino-test) — Run the Arduino simulator e2e suite (pytest).
